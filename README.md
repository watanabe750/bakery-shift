# bakery-shift

パン屋の製造リーダー・店長向けの希望休回収・製造シフト作成アプリ

## 目的

紙で集めた希望休を見ながら月間シフトを作成する負担を減らし、製造メンバーの出勤日と担当ポジションを見やすく管理すること。

## MVP機能

- スタッフ登録
- ポジション設定
- 希望休提出
- 希望休一覧
- 製造シフト作成
- 下書き / 公開
- 印刷

## 対象ユーザー

- パン製造リーダー
- 店長
- パン製造スタッフ

## 技術構成

- Next.js
- TypeScript
- Tailwind CSS
- Supabase
- Vercel
